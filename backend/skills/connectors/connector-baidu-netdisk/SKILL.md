# 百度网盘连接器

通过已授权的百度网盘 MCP 浏览、检索和管理用户的云端文件。Access Token 由连接器管理，不向用户索取或展示。

## 能力边界

- 支持目录和分类浏览、文件名搜索、内容与语义检索、文件元信息、账号信息和容量查询。
- 支持新建文件夹、复制、移动、重命名、创建分享链接、保存文本内容和通过公开 URL 转存文件。
- 当前远程 SSE 工具集不提供任意本地文件上传、下载到本地或删除文件的能力。
- 不要把文本保存或 URL 转存描述为完整的本地文件上传。

## 调用原则

- 涉及百度网盘时优先调用本连接器的 MCP 工具，不使用本地文件系统命令代替。
- 目标路径不明确时先浏览或搜索；工具要求路径时使用以 `/` 开头的绝对网盘路径。
- 用户只要求查找或查看时保持只读，不顺带整理、分享或转存。
- 新建、复制、移动、重命名、转存或创建分享链接前，确认目标对象、目录、名称和冲突策略。
- 未明确授权时不覆盖已有文件；默认优先生成副本名或跳过。
- 搜索结果较多时使用分页或数量限制，并说明结果范围。

## 工具选择

- 查看目录内容使用通用文件列表；只查看文档、图片或视频时使用对应分类列表。
- 查询文件详情前先从列表或搜索结果取得文件 ID；单次最多查询 10 个文件 ID。
- 查询账号和网盘容量时分别使用用户信息与空间配额工具。
- 用户指定文件类型或后缀时，同时设置分类或扩展名过滤，减少无关结果。

## 搜索与文件管理

- 明确文件名关键词优先使用文件名搜索；自然语言描述内容、主题、场景、时间或地点时使用语义检索。
- 搜索图片文字时使用 OCR 来源；搜索文档正文时使用文档内容来源。
- 复制、移动或重命名前先从列表或搜索结果确认源文件及目标目录。
- 查询文件详情时先取得文件 ID，并遵守工具的单次数量限制。
- 新建文件夹前确认完整目标路径；同名冲突时优先自动重命名，不默认覆盖。
- 移动、复制和重命名时确认源文件绝对路径、目标目录和目标名称。

## 分享与保存

- 创建分享链接前确认文件、有效期、4 位提取码和备注；提取码只能由数字和小写字母组成。成功后只向当前用户返回链接信息，不声称已发送给联系人。
- 保存会议纪要或生成内容时使用文本保存工具，单次文本不超过 2 万字。
- 用户未指定目录时，先告知默认位置 `/来自：mcp_server` 或询问目标目录。
- 用户未指定文件名时，工具可能默认保存为 DOCX；优先确认文件名和扩展名。
- URL 转存仅适用于可直接下载、无需额外登录或验证码的地址。

## 使用示例

- 查看百度网盘根目录并查询剩余空间。
- 从文件名、文档正文和图片 OCR 文字中搜索“项目合同”。
- 找出与海边日落相关的图片和视频。
- 新建“AIGC 调研资料”文件夹并复制相关文件，遇到同名文件时生成副本。
- 为“周报.docx”创建有效期 7 天、带 4 位提取码的分享链接。
- 将会议纪要保存为“产品会议纪要.docx”，或把公开下载链接转存到“参考资料”。

## 错误处理

- 返回 401、403、Access Token 无效或过期时，提醒用户在连接器管理中重新连接百度网盘，不输出 Token。
- 文件不存在时重新浏览父目录或搜索，避免基于猜测继续操作。
- 同名冲突时列出生成副本、覆盖、跳过或失败选项，不擅自覆盖。
- 语义检索无结果时缩短描述、调整搜索来源或取消过窄筛选。

## 安全说明

- 禁止在对话、日志、命令或输出文件中展示完整 Access Token。
- 未经明确确认，不移动、重命名或覆盖重要文件，也不创建公开分享链接。
- 分享链接、提取码和文件路径可能包含敏感信息，只向当前用户展示。
