# 资格、证明与固定响应编写

## 一、目标

资格和证明章节只回答：

```text
是否满足
→ 依据什么事实
→ 使用什么证明材料
→ 材料放在投标文件什么位置
→ 是否存在待补或冲突
```

不得扩写成企业宣传材料。

## 二、叙述型资格说明

可使用：

```text
招标要求和来源
→ 响应结论
→ 已确认事实
→ 证明材料及其证明事项
→ 有效期、主体、标包和适用范围
```

待补、冲突和材料缺口记录在待补清单或明确占位中，不在正式证明文字中暴露内部编号。

## 三、资格表格

资格表格常见列包括：

- 资格要求；
- 响应情况；
- 证明材料；
- 对应位置；
- 页码。

必须逐列理解：

- `响应情况` 可以写事实和结论；
- `响应文件章节及条款号` 只能写投标文件位置；
- `证明材料/对应位置` 填写材料名称和所在章节；
- `页码` 等最终排版后回填，不得猜测。

不得因为参考标书使用“响应情况”列，就把同样的响应文字写进当前项目的“响应文件章节及条款号”列。

## 四、材料判断

- 只凭材料内容判断，不凭文件名；
- 证书、业绩、人员、财务和授权需检查主体、时间、完整性和项目匹配；
- 材料存在但无效，不能写成满足；
- 缺材料与不具备资格要准确区分；
- 若资格事实已确认但证明文件尚缺，偏差状态仍按实际情况判断，材料缺口进入待补清单；
- 若资格事实本身未确认，不得声明具备，也不得在偏差表中写“无偏差”。

## 五、固定表单

- 只提供允许填写的动态值；
- 不重写模板标签和固定文字；
- 保留原有括号、下划线语义和签章区域；
- 不用“信誉良好、实力雄厚、经验丰富”代替证明；
- 不把多个填空位合并成一段新句子。
