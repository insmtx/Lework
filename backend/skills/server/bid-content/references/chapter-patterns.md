# 章节原型

章节原型用于选择论证方式，不是固定目录。标题和层级以锁定目录为准，只选取与当前章节任务有关的内容。

## 1. 项目理解型

适用于项目概述、需求理解、总体认识。

建议顺序：

```text
项目背景与建设目标
→ 使用主体和业务场景
→ 现状约束或需要解决的问题
→ 建设范围与系统边界
→ 总体架构或能力关系
→ 端到端业务流程
→ 建设重点
→ 实施难点及解决路线
→ 整体响应策略
```

关键要求：不能只复述采购清单；重点和难点必须说明成因、影响和应对路线。

## 2. 总体架构型

```text
架构目标与约束
→ 设计原则
→ 分层或模块架构
→ 各层职责
→ 模块调用关系
→ 数据流与任务流
→ 部署关系
→ 安全、扩展和异常处理
→ 架构验证方式
```

关键要求：不能只画层次框图；每个模块的存在理由和相互关系必须在正文中解释。

## 3. 技术能力型

适用于识别、分析、处理、算法、平台能力等。

```text
处理对象与场景
→ 输入条件和前处理
→ 核心机制
→ 处理步骤
→ 后处理与质量控制
→ 输出结构
→ 边界与异常处理
→ 性能或效果验证
```

## 4. 接口与数据集成型

```text
集成对象与边界
→ 调用模式
→ 请求与任务生命周期
→ 数据格式和字段规则
→ 鉴权与权限
→ 同步/异步、查询和回调
→ 幂等、重试和异常码
→ 日志与审计
→ 联调和验收
```

## 5. 部署与适配型

```text
目标环境和前置条件
→ 节点、网络、存储和依赖规划
→ 安装与配置流程
→ 授权和离线资源管理
→ 兼容性适配方法
→ 健康检查、备份和回退
→ 性能调优
→ 部署验证和交付物
```

## 6. 性能与高可用型

```text
指标与适用条件
→ 容量和负载模型
→ 并发与任务调度机制
→ 节点和资源规划
→ 健康检查、故障隔离和恢复
→ 扩展方式
→ 监控指标
→ 测试场景、数据和判定
```

## 7. 安全与合规型

```text
保护对象和威胁边界
→ 身份与权限
→ 数据传输、存储和使用控制
→ 系统与接口安全
→ 日志、审计和告警
→ 漏洞、事件和应急处理
→ 合规记录和验证
```

不得承诺绝对安全或零风险。

## 8. 实施与项目管理型

```text
实施目标和范围
→ 前置条件和双方输入
→ 阶段划分
→ 各阶段任务、责任和输出
→ 依赖和里程碑
→ 质量检查点
→ 沟通、问题和变更闭环
→ 风险和恢复安排
```

## 9. 测试与验收型

```text
验收依据和范围
→ 环境、数据和角色
→ 测试类型与步骤
→ 指标口径和判定规则
→ 记录、报告和证据
→ 缺陷整改
→ 复验和最终交接
```

## 10. 服务与售后型

```text
服务范围和边界
→ 服务入口与登记
→ 分类分级
→ 响应、诊断和处理
→ 升级与协同
→ 恢复确认
→ 关闭、回访和报告
→ 知识库和持续改进
```

响应、到场、开始处理和恢复不能混为一个时限。

## 11. 培训与知识转移型

```text
培训对象和能力目标
→ 课程与分层内容
→ 方式、环境和材料
→ 讲师角色与组织
→ 实操、考核和记录
→ 补训与答疑
→ 运维接管和知识移交
```

## 12. 资格与证明型

```text
要求和结论
→ 已确认事实
→ 证明材料及证明事项
→ 适用范围和有效性
→ 待补、冲突或不适用说明
```

不扩写为企业宣传。
