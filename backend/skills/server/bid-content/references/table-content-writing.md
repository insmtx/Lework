# 标书表格内容编写

## 一、目标

标书表格不是普通 Markdown 表格。每个表头都代表一个明确的评审字段、事实字段、位置字段或金额字段。填写前必须先理解字段语义，再生成单元格内容。

不得因为某一列“看起来能放下更多信息”，就把响应说明、证明材料、待补事项和内部备注混写到同一列。

## 二、表格理解顺序

处理任何表格前，依次确认：

1. 表格名称和所在章节；
2. 表头原文、列顺序和多级表头关系；
3. 是否存在合并单元格；
4. 一行代表什么对象；
5. 每一列要表达什么；
6. 每一列的数据类型；
7. 每一列的数据来源；
8. 缺失时如何处理；
9. 是否需要引用最终章节、附件或页码；
10. 是否需要在其他章节完成后再生成。

## 三、常见表头语义

以下规则是通用解释。当前项目仍以底板原始表头和填写说明为准。

| 表头 | 字段语义 | 应填写内容 | 禁止内容 |
|---|---|---|---|
| 序号 | 当前表格中的行编号 | 连续数字 | 招标条款号、内部 ID |
| 招标文件章节及条款号 / 询比文件章节及条款号 | 要求在招标文件中的来源位置 | 真实章节、条款号及必要摘要 | 响应正文、投标文件位置 |
| 响应文件章节及条款号 / 投标文件章节及条款号 | 当前响应在投标文件中的位置 | 目录节点 + 小节/条款位置 | 响应叙述、产品参数、内部文件路径 |
| 响应情况 / 响应内容 | 对要求的实际响应 | 响应结论、能力、实施安排或证明情况 | 只有章节位置，除非表头另有说明 |
| 偏差说明 | 相对招标要求的差异结论 | 无偏差、正偏差、负偏差、部分偏差及具体差异 | 材料缺口、PEND 编号、审查意见 |
| 证明材料 / 对应位置 | 证明某项事实或资格的材料位置 | 附件名称、章节、小节或证书位置 | 宣传文字、模糊“见附件” |
| 页码 | 最终成稿中的页码 | 最终排版后回填的页码 | 估算页码、Markdown 行号 |
| 分项名称 | 招标方定义的报价或交付分项 | 模板分项名称或经确认名称 | 自行拆分或合并后的名称 |
| 服务内容 / 技术内容 | 对当前分项的范围说明 | 从已完成方案中压缩得到的内容 | 与分项无关的全部产品介绍 |
| 单价 / 总价 | 金额字段 | 用户确认或权威输入中的金额 | 推算、平均分摊、猜测 |
| 规格型号 | 实际投标产品型号 | 材料或用户确认的型号 | 自行创造的型号 |
| 备注 | 模板指定的补充事项 | 与当前行直接相关的正式备注 | 内部待办、材料缺口、审查状态 |

## 四、行粒度

先判断“一行代表什么”，再生成表格：

- 资格表：一行通常代表一项资格要求；
- 业绩表：一行代表一个真实项目业绩；
- 人员表：一行代表一名真实人员；
- 证书表：一行代表一项证书或一个证书类别；
- 报价表：一行代表一个模板分项；
- 技术参数表：一行代表一个可独立响应和验收的参数；
- 偏差表：一行代表一个单一、可定位的来源条款，不合并小节、子项、表格行或并列条款；
- 索引表：一行代表一个评审因素、资格项或要求项。

不得为了缩短表格把不同责任、不同证明方式或不同偏差结论的事项合并到一行。

## 五、字段值来源

每个单元格都应能追溯到以下一种来源：

- 招标文件原文；
- 锁定目录中的真实章节；
- 已确认企业事实；
- 已确认产品事实；
- 已验证材料；
- 用户确认的金额、日期、人员或承诺；
- 明确可见的待补占位。

不能从参考标书、文件名、行业常识或上下文推断出确定性值。

## 六、缺失值处理

### 1. 普通字段缺失

使用：

```text
【待补充：字段名称】
```

### 2. 页码未生成

使用：

```text
【待回填页码】
```

### 3. 金额未确认

使用：

```text
【待补充：单价】
【待补充：总价】
```

### 4. 证明材料缺失

- 在材料位置字段中使用明确占位；
- 同时保留到待补清单；
- 不把内部待补编号放入正式表格；
- 不把材料缺失写入“偏差说明”，除非材料缺失本身已被确认导致不满足要求。

## 七、表格与正文关系

- 表格中的章节引用必须指向真实正文；
- 表格中的服务内容应从正式方案压缩，不得反向创造正文中不存在的能力；
- 表格中的参数和承诺必须与正文一致；
- 正文变化后，所有引用该正文的表格都要重新检查；
- 表格不得引用尚未生成的目录节点。

## 八、正式表格禁止项

正式表格中不得出现：

- `REQ-*`、`FACT-*`、`MAT-*`、`PEND-*`、`OUT-*`；
- Markdown 文件路径；
- “待后续审查”“模型判断”“需进一步确认”等工作语言；
- 证据审核状态；
- 临时章节号；
- 无法在最终投标文件中查找到的引用位置；
- 为了显得完整而编造的金额、页码、人员、日期、证书或参数。
