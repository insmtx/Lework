## 写作完成判断

- [ ] 已覆盖要求/评分点；
- [ ] 主要主题不是从功能表开始，至少有定位、机制和收束动作；
- [ ] 句子主语、过渡关系和主动动作与全篇风格一致；
- [ ] 每个实质单元都说明机制、控制和验证；
- [ ] 未把设计、承诺或目标写成无依据既有事实；
- [ ] 可直接据此写正式 Markdown，不需要再生成独立研究、骨架或候选文件。
