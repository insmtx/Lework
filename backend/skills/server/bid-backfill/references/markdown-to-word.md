# Markdown 转 Word 处理说明

本说明只指导 Markdown 到 Word 的语义转换和样式选择，不能改变已锁定的目录、模板目标、表格结构、锚点或保护范围。

## 一、总体处理思路

1. **先识别结构，再写入。** 先区分标题、段落、列表、表格、引用、代码块、链接、图片和行内强调，再决定对应的 Word 对象；不要把 Markdown 原文整段粘贴进 DOCX。
2. **先确认目标，再转换。** 依据 `填写说明.md` 找到唯一的正文插入点、字段槽位、表格数据区或附件位置。Markdown 的标题只能帮助确认内容归属，不能创建新目录或覆盖模板标题。
3. **优先沿用模板。** 转换后的段落、字符、列表和表格样式，优先复制目标位置或相邻模板样本的既有样式；只有模板没有直接对应样式时，才选择最接近的模板样式作合理处理。
4. **保留语义和顺序。** 保持来源内容的段落顺序、列表层级、表格行列、强调关系、链接目标和图片关系。没有直接对应样式时，按填写位置和相邻模板内容自适应选择最近的 Word 样式；只要结构和语义能够表达就继续转换，最终不得保留 Markdown 标记。只有目标结构不明确、语义无法表达或会破坏受保护边界时才停止。

## 二、字体和段落样式选择

按以下优先级决定转换后的文字样式：

1. 当前目标位置的模板样本（同一插入区、同一表格单元格或相邻同类段落）；
2. 当前章节中同类内容已经使用的模板样式；
3. 底板中已存在的最接近的标题、正文、列表、表格或附件说明样式；
4. 只有找不到可继承样式时，才使用合理的统一默认值，并在同一章节内保持一致。

字体处理以模板为主：保留模板的中文字体、西文字体、字号、颜色、字符间距、加粗/倾斜、段前段后距、行距、缩进和对齐方式。Markdown 的加粗、斜体等语义只在此基础上增加对应字符属性，不整体重设字体。不要凭常见标书习惯自行指定宋体、黑体、字号或蓝色链接，也不要让转换工具的默认样式覆盖模板样式。

表格、列表和代码块优先复制同类模板对象的样式；追加表格行仍遵守 `TABLE-FILL` 的完整样本行复制要求。没有直接对应样式时，按填写位置继承相邻正文或表格样式，再根据内容自适应调整必要的段落和字符属性；不得让转换工具的默认 Markdown 样式覆盖模板整体格式。

## 三、不同 Markdown 写法的处理边界

- 常见 Markdown 和 GFM 写法可以按上述结构思路归并处理；首尾竖线、可选的列表标记和常见行内强调不应改变最终 Word 语义。
- 围栏代码内的内容按代码处理，不把其中的符号继续解析为标题、列表或强调。
- HTML、数学公式、脚注、Mermaid、嵌入对象、特殊扩展指令等语法，只有在当前项目存在明确的 Word 表达方式时才转换。
- 语法未闭合、表格列无法对应、链接或图片目标不清，或一种写法可能对应多个模板目标时，停止并退回内容/模板阶段确认。样式无法直接继承不是停止理由，应按填写位置选择合理的 Word 样式继续转换。
- 任何无法确认的事实继续使用 `【待补充：具体内容】`，不能因为转换方便而补写内容。

## 四、转换后检查

完成当前单元后，至少检查：

- 来源结构与 Word 内容顺序一致，标题、列表、表格和附件没有漏项或串位；
- DOCX 中没有可见的 Markdown 标记、伪列表、竖线表格或无意保留的代码围栏；
- 新内容的字体、字号、颜色、行距、缩进、对齐和表格样式与相邻模板内容统一；
- 链接、图片、待补占位和代码换行仍可追溯、可读；
- 重新打开 DOCX 并渲染当前页及相邻页，确认无溢出、截断、乱码、异常空白页或样式跳变。

## 五、Markdown 语法与对应处理方式

| Markdown 语法 | 对应 Word 处理方式 | 样式依据与边界 |
|---|---|---|
| `# 标题` 至 `###### 标题` | 转为对应层级的 Word 标题段落 | 使用目录和填写说明确认的标题级别及模板样式，不重复写入手工编号。 |
| 普通文本段落 | 转为 Word 正文段落 | 继承正文插入区或相邻同类段落的字体、字号、行距和段落间距。 |
| `**加粗**`、`*斜体*` | 转为字符加粗或倾斜 | 只增加对应字符属性，不重设模板字体、字号和颜色。 |
| `` `行内代码` `` | 转为行内代码字符样式或等宽字符 | 优先沿用模板已有样式；没有对应样式时采用统一、克制的正文表达。 |
| `-`、`*`、`+` 无序列表 | 转为 Word 项目符号列表 | 使用模板已有编号定义，保留列表层级，不保留 Markdown 符号。 |
| `1.`、`1)` 有序列表 | 转为 Word 编号列表 | 使用模板已有编号定义，不保留 Markdown 手写序号。 |
| `> 引用内容` | 转为引用样式或缩进段落 | 优先使用模板已有引用对象；不能破坏正文整体版式。 |
| 围栏代码（三个反引号或三个波浪号） | 转为预格式/等宽段落，保留代码换行 | 不擅自添加语法高亮；没有对应样式时，确认能否安全转为普通说明段落。 |
| Markdown/GFM 表格 | 按下方“Markdown 表格到 Word 表格的分流处理”选择模板表格填写或完整表格插入 | 不直接假定为数据区，先确认填写说明中的场景和目标。 |
| `[显示文字](链接)` | 保留显示文字并建立 Word 超链接 | 不写入方括号和圆括号；不强行覆盖模板原有字体颜色。 |
| `![替代文字](图片路径)` | 在授权图片/附件位置插入真实图片 | 资源缺失时使用待补占位，不以路径或替代文字冒充图片。 |
| `---`、`***`、`___` 分隔线 | 使用模板已有的分隔线、边框或段落表达 | 没有对应对象时，不用连续短横线或空行模拟。 |
| 行尾两个空格或反斜杠硬换行 | 转为同一 Word 段落中的换行 | 与普通空行区分，不制造多余空段。 |
| `\*`、`\|` 等转义字符 | 还原为对应的普通文字 | 不把转义符本身写入 Word；表格中的转义竖线仍按文字处理。 |
| HTML、数学公式、脚注、Mermaid 等扩展语法 | 能以普通文字表达的内容，按填写位置的正文样式转换；需要专用对象的内容，按模板目标处理 | 不得保留原始 Markdown/HTML 标记；只有专用语义无法表达且继续转换会造成内容误读时才停止。 |

## 六、Markdown 表格到 Word 表格的分流处理

| 处理场景 | 适用目标和规则 | Markdown 到 Word 的处理方式 | 重点检查 |
|---|---|---|---|
| 标书模板里的表格填写 | 填写说明已定位 Word 表格、表头、数据起始行和模板样本行；适用 `TABLE-FILL` | Markdown 表头只用于字段对应和列校验；沿用 Word 表头、列顺序、合并关系、列宽、边框和样本行，只向授权数据区写入内容。追加行复制完整样本行，不重建表头。普通数据内容单元格垂直居中、左对齐；序号及类似短字段水平、垂直居中。数据行允许自动换行，行高根据内容自适应；不得使用固定精确行高截断文字。 | 列数、字段语义、单位、数据起点、合并关系、行数、普通数据单元格垂直居中/左对齐、序号类单元格水平/垂直居中、自动换行、内容自适应行高和跨页表头均与模板要求一致；不把 Markdown 表头覆盖到 Word 表头。 |
| 自拟正文待填写的完整表格 | 填写说明明确正文插入点允许插入完整表格，并确认表格用途、列结构和样式；适用 `SECTION-INSERT` | Markdown 表头、数据行和必要的对齐信息可以作为完整表格内容来源；在插入点创建或插入完整 Word 表格，使用模板中最接近的表格样式。正文表格边框使用单线 `single/sz=4/color=000000`，表头行加粗，数据行字体、字号和语言字体与模板同类正文/表格样式一致。 | 表格整体顺序、表头、列数、行数、单线边框、表头加粗、数据行字体样式和分页均可读；不能因模板没有现成数据表就随意改变目录或正文锚点。 |
| 场景无法确认或两者不匹配 | 填写说明没有明确表格目标、数据区或完整表格插入授权 | 停止当前单元，退回模板或内容阶段确认；不把表格降级为竖线文本、制表符文本或截图。 | 保留上一份已验证候选，待场景、目标和样式确认后再回填。 |
