# 条款响应与偏差表

## 写法

1. 保留单一来源条款的准确定位；
2. 写该条款对应的唯一响应位置；
3. 写与该条款直接对应的具体响应、履约动作、能力、参数、流程、时限、交付物或责任；
4. 给出该条款的偏差结论；
5. 必要时在独立字段或附件位置记录证明材料。

“完全响应，无偏差”不能替代具体响应。无偏差说明应先给出结论，再用一句已确认且与本条款直接对应的承诺说明响应内容；不得以套话、内部状态或材料缺口代替承诺。

## 全量与仅列偏差

根据官方模板说明决定是否列出全部响应或仅列出偏差。无论展示范围如何，Skill 默认保留全量来源单元映射；需要展示的商务、技术条款必须逐条独立列出，不得合并来源或省略响应位置。
