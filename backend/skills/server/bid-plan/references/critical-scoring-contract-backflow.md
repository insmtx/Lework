# 强制、评分和合同回流

## 强制/否决

识别“不接受、不得、必须、应当、无效、废标、否决、★、实质性”等语义，并记录原文、后果和证明需求。不得把所有“应”机械判断为否决项。

## 评分

每个评分行拆出：评分对象、条件、证明材料、分值/档次、对应资格/商务/技术要求和正文增强位置。评分属性不能替代原始分类。

## 合同

逐项提取供应商义务并回流：付款、交付、验收、保密、知识产权、数据、人员、服务、违约等归商务；技术支持、维护、升级、性能和安全义务归技术。采购人权利或义务可排除，但需理由。

## 模板承诺

响应函、报价函和承诺书中的固定承诺也是要求来源，必须登记并与其他来源交叉关联。
