# 商务与技术要求提取规则

## 原子化判断

以正式文件中最小的独立小节、子项或表格行作为来源单元，并逐一登记。即使相邻来源的主题、响应位置或偏差结论相同，也不得合并为一条要求或一行偏差表。满足任一条件时，应额外检查该来源单元是否包含需要另行定位的下级来源单元：

- 可以独立承诺或偏离；
- 有独立数值、时限、范围、对象或责任；
- 可以独立验收、评分、举证、否决或追责；
- 是独立功能、格式、接口、交付物、服务动作或保障措施。

连接词“并、且、以及、同时、分别、包括”可提示存在下级编号项或表格行需要继续提取；没有独立来源定位时，仍以当前最小来源单元为界，不凭语义将不同条款拼接或拆成虚构条款。

## 商务候选池

报价构成、税费、发票、有效期、保证金、合同签订、交付期、地点、运输安装费用、付款条件、验收付款关系、质保/服务期限、保密、知识产权、数据归属、转包分包、人员责任、违约赔偿、变更终止和争议解决等。资格条件、文件格式、平台操作和评审程序不进入商务或技术偏差表，应在其所属响应位置单独覆盖。

## 技术候选池

功能、性能、输入输出、专项识别、接口、部署、兼容、数据、安全、权限、日志、实施、项目管理、测试、验收、培训、技术支持、运维、售后和技术交付物等。

## 偏差表归属

来源章节和条款性质优先于措辞判断。独立的技术、实施、验收、培训、运维或售后服务要求进入技术偏差表；独立的核心商务义务进入商务偏差表。每条进入偏差表的要求都必须保留单一来源条款、单一响应位置和单一偏差说明，禁止展示归并。
