# 独立审查协议

## 范围

在 `bid-final-review` 中启动一次独立的全量审查。审查对象是完整候选 DOCX、其渲染页、招标要求、确认事实、待补项和填写说明；不以逐章状态或中间审查结论作为验收对象。

## 强制条件

- 审查执行者只读，不得参与 Markdown 编写、模板生成或 DOCX 回填。
- 审查执行者直接形成包含范围、审查者、结论、问题计数、findings 和证据的 Markdown 报告；报告必须有固定格式的结论行 `审查结论：通过`、`审查结论：需要修改` 或 `审查结论：不通过`。
- `blocking` 或 `major` finding 存在时，结论不得是“审查结论：通过”。

## 审查维度

1. 招标要求是否在完整 DOCX 中有真实、正确的响应位置；
2. 投标方、项目、产品、金额、期限和待补占位是否与确认资料一致；
3. 模板固定内容、字段、表格、目录、页眉页脚和签章区域是否保全；
4. 渲染页是否存在裁切、溢出、乱码、异常空白、表格或分页问题；
5. 输出是否仅包含最终 DOCX 和待补充清单。

## 返修

- 内容、资料或待补问题：返回 `bid-content`，随后重新完整回填。
- 模板、字段、表格、分页或版式问题：返回 `bid-backfill`。
- 每次返修后从新候选 DOCX 发起新的审查；不得复用旧结论。
