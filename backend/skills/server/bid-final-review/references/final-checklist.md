# 最终内容与交付检查清单

整体格式检查按 `references/overall-format-check.md` 单独执行。本清单只检查最终内容、事实、待补项和交付状态：

- 独立审查官对完整候选返回 `conclusion: passed`，且 blocking/major 均为 0；
- DOCX 中的 `【待补充：具体内容】` 与待补清单和项目状态一致，未静默删除、隐藏或替换为虚构内容；
- DOCX 中的响应内容与已确认事实、材料、要求覆盖关系、偏差表和其他章节一致；
- 未出现虚构的企业、产品、案例、人员、证书、指标、金额、期限、服务等级或验收结论；
- 强制项、否决项、合同义务、报价和附件要求均有可定位的响应或明确的待补边界；
- 从原始正式文件逐条回查商务、技术偏差表：每个进入偏差表的来源小节、子项或表格行均有一个要求记录、一行表格、一个真实 Markdown 响应小节和一个 DOCX 行；
- 每一行偏差表的来源条款均为单一、可定位的正式条款，未并列或合并其他来源；
- 每一行的响应位置真实存在且指向实质内容；偏差说明与该单一条款、正文和已确认承诺一致，并包含具体响应承诺或具体差异；
- 资格、文件格式、平台操作和评审程序未误入商务或技术偏差表，但仍在其对应响应位置完成覆盖；
- Markdown 内容已被正确表达为 Word 内容，未出现语义遗漏、错位或未经授权的内容改写；
- `output/` 仅有一份最终 DOCX 和一份待补充清单 Markdown。

最终内容与交付检查以完整候选 DOCX、整体格式检查结果、内容审查证据和本阶段形成的审查结论为依据。
