# 模板填写说明

> 本文件按章节记录模板中需要填写的识别内容。每个章节只使用一个表格；章节位置、填写目标、内容形态、填写规则、固定保护和版式要求全部写在该章节表格中。本文件不记录最终事实、具体材料、附件清单或待补事项。

## 使用规则

通用 DOCX 操作规则见 `references/filling-rules.md`。表格中的“填写规则”只能使用该文件定义的规则名称：`FIELD-UNDERLINE`、`MIXED-RUN`、`TABLE-FILL`、`SECTION-INSERT`、`SECTION-LAYOUT`、`ATTACHMENT-SIGN`、`TEMPLATE-PROTECT`。

缺失信息统一使用 `【待补充：具体内容】` 作为占位。这里只声明占位方式，不列出具体待补信息。

## 占位规则

对于模板要求填写但当前没有确定值的字段、表格单元格、正文位置或附件位置，保留：

```text
【待补充：具体内容】
```

占位必须放在对应模板位置，不能删除标签、固定文字、签章线或结构，也不能用虚构内容替代。具体内容由后续内容准备和回填阶段根据实际资料提供。
